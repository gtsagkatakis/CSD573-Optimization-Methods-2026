# CS-573 Optimization Methods: interactive demos

Browser demos used in CS-573 / HY573 Optimization Methods, a graduate course at
the Computer Science Department, University of Crete.

Each demo is a single HTML file with no dependencies. Open it in any modern
browser, online or offline. They are built for the lecture room (large type,
projector-friendly) and work on phones.

## Lecture 1: Introduction, vectors

| Demo | Idea |
|---|---|
| [Fit the line by hand](cs573_demo1_fit_the_line.html) | Least squares as an optimization problem; the loss surface in 2D and 3D |
| [Text as a vector](cs573_demo2_bag_of_words.html) | Bag of words; what the representation keeps and what it discards |
| [Three vector norms](cs573_demo5_three_norms.html) | l1, l2 and l-infinity of a vector you can drag |
| [Norm balls](cs573_demo3_norm_balls.html) | Unit balls for general p, convexity, and why l1 gives sparse solutions |
| [Who has similar taste?](cs573_demo6_inner_product_ratings.html) | Inner product versus cosine similarity on movie ratings |
| [Span of two vectors](cs573_demo4_span_2d_3d.html) | Linear combinations in 2D; a plane in 3D, and points on or off it |
| [Orthonormal expansion](cs573_demo7_orthonormal_expansion.html) | Keep K coefficients; denoising and the best K |
| [Projection](cs573_demo8_projection.html) | The closest point, orthogonality of the error, and the normal equations |

More demos will be added as the course progresses.

## How to use them

Most demos follow the same pattern: predict, try by hand, then reveal. Panels
can be hidden before class and shown after students have voted.
